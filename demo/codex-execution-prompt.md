## 推荐执行顺序

1. 先执行 `Task 0.1`：确认 MVP 范围和降级边界。
2. 再执行 `Task 0.2`：建立测试样本和人工标注基线。
3. 然后执行 `Task 1.1`：验证 3 路匿名直播并行播放。
4. `Task 1.1` 通过后，再进入 `Task 1.2` 独立音频捕获。

- 不建议一上来搭完整客户端。
