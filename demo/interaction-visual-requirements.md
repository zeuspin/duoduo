# 多多直播交互与视觉需求

版本：V0.1  
日期：2026-07-11  
视觉参考：[Admindek Course View](https://demo.dashboardpack.com/admindek-html/admins/course-course-view.html)

## 1. 应用骨架

- 固定深色左侧菜单，首个菜单为“直播间管理”。
- 固定浅色顶部栏，仅保留菜单折叠、直播间搜索和本机用户入口。
- 不实现顶部通知入口。
- 不实现左侧底部“当前监看 / 负载 / ASR 延迟”区域。
- 主工作区为浅灰背景，内容使用白色连续表面、边框和分隔线。

## 2. 页面结构

1. 页面标题、说明和“添加直播间”。
2. “实时监看中”单列区域。
3. “预备直播间”卡片网格。
4. 右侧单路音视频播放与历史 ASR 抽屉。
5. 不设置集中混排多个直播间的全局 ASR 区域。

## 3. 监看卡片

- 一路一张横向卡片，一张卡片独占一行。
- 左侧为直播主图和直播状态。
- 中部为主播名称、标题、在线人数、点赞增速、热度曲线、预计周期、停止监看和播放操作。
- 右侧只显示该直播间最新 ASR，区域内部自动滚动。
- 点击 ASR 行打开当前直播间抽屉并定位时间。
- 无语音时显示“等待主播说话”，不得混入其他直播间文本。

## 4. 预备直播间卡片

- 三列图片卡片网格；窗口变窄时可降为两列。
- 重点展示主图、主播名称、直播状态、人数、点赞、热度和周期。
- 已开播卡片提供“加入实时监看”和“播放”。
- 未开播卡片禁用监看和播放。
- 开启监看后卡片迁移到上方并变为横向监看卡片。

## 5. 添加直播间

- 对话框包含标准直播间链接、星期选择、开始时间、结束时间和增加时段。
- 默认选择周一至周五和 `09:00–12:00`，用户可以修改。
- 明示“添加后进入初始化，不会自动监看，也不会播放声音”。

## 6. 播放抽屉

- 固定在窗口右侧，宽度约 420px。
- 播放画面为 9:16。
- 展示当前在线人数、点赞、回到直播和关闭。
- 下方为当前直播间历史 ASR，点击时间进入回放。
- 关闭抽屉后该直播间仍保持静默监看。

## 7. 视觉约束

- 使用 Inter 和中文系统字体，字距为 0。
- 内容卡片、按钮、状态标签、ASR 行、弹窗和提示使用直角。
- 仅头像、计数、状态圆点和顶部品牌标记允许圆形或小圆角。
- 不使用胶囊标签、渐变、装饰光斑和卡片嵌套。
- 主色为克制蓝色；直播使用红色，播放使用绿色，禁用使用中性灰。
- 操作使用 Phosphor 图标；陌生图标必须有 tooltip 或可访问名称。

## 8. 原型基线

- 可交互原型：`demo/prototype/`
- 视觉验收：`demo/prototype/design-qa.md`
- 已验证交互：卡片双向迁移、独立 ASR、单路播放抽屉、历史 ASR 点击、添加周期。
