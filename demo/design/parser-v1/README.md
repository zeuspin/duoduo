# 大模型解析器交互设计 V1

状态：待产品确认  
日期：2026-07-13

## 设计目标

在保留完整 ASR 证据的前提下，让用户默认阅读经过大模型提炼的市场观点，降低寒暄、广告、观众提问和未认可转述造成的信息干扰。

首个内置解析器命名为“市场观点与情绪提炼”，关注：

- 板块方向和市场风格；
- 指数、成交量、涨跌家数、资金等指标的解释；
- 市场情绪及情绪转折；
- 条件性判断和风险信号；
- 观点变化以及对应的自然时间和 ASR 原文证据。

## 核心交互约束

1. 解析器是可复用模板，不在每个直播间内单独维护提示词。
2. 一个直播间同一时间最多绑定一个正式主解析器，也可以选择“不使用解析器”。
3. 编辑正式解析器时创建测试草稿，正式版本继续工作。
4. 测试草稿默认只重放历史 ASR，不进入正式观点流，也不触发警示。
5. 发布测试草稿后生成不可变的新版本；旧版本保留回滚能力。
6. 观点结论必须携带证据原文、自然时间、观点性质和置信度。
7. “系统推断”不能伪装成主播明确观点，默认降低视觉权重。
8. 板块别名允许建议标准名称，但低置信度时保留主播原话，不强制归类。

## 可交互原型

浏览器原型支持以下操作：

- 从侧栏在解析器管理、直播间绑定、观点阅读和验证方案之间导航；
- 新建或编辑解析器时进入测试草稿编辑区；
- 保存草稿时明确提示正式版本未受影响；
- 为每个直播间切换主解析器或选择“不使用解析器”；
- 使用相同 ASR 样本重新运行版本对照；
- 删除测试草稿前确认影响范围；
- 发布新版本前确认绑定直播间和历史结果的处理方式；
- 发布后把正式版本从 v1.3 更新为 v1.4，并移除已发布草稿行。

## 待确认决策

- 观点中心是否需要跨直播间聚合，还是首版只在单个直播间内阅读。
- 低置信度“系统推断”是否默认显示，还是仅在筛选后显示。
- 测试草稿是否允许 10–20 分钟实时旁路，还是首版只支持历史 ASR 重放。
- 用户是否可以直接编辑高级提示词；当前建议放在高级设置中，不作为默认编辑方式。
