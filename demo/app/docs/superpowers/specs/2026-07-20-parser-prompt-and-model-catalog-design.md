# 解析器提示词与模型目录改版设计

## 1. 目标

简化解析器的新建和复制新建流程，让用户直接选择经过验证的百炼文本模型，并看到对应计费规则；解析器实际使用的所有指令以完整文本提示词呈现，不再由关注内容、忽略内容或名称规范化等隐藏选项拼装。

本次改动不得影响直播监看、ASR、组级解析器绑定、内容分析或 AI 用量统计主流程。

## 2. 用户界面

### 2.1 新建与复制新建

编辑表单只保留三个字段：

1. 解析器名称，必填，1–80 个字符。
2. 模型，从受控模型目录中单选，不允许自由输入模型 ID。
3. 用户提示词，必填，展示并保存模型实际收到的完整解析指令。

移除以下表单项：

- 解析器说明。
- 关注内容。
- 忽略内容。
- 名称规范化。
- 高级提示词。
- 测试直播间。
- 运行样本测试及测试结果。

保存按钮保持“创建并保存”。解析器创建后仍不可编辑，只能查看、复制新建或删除。

### 2.2 模型计费规则

模型下拉按“推荐”“千问”“DeepSeek”“其他”分组。每个选项显示用户可理解的名称与定位，保存时使用官方模型 ID。

选择模型后，表单紧邻显示：

- 模型定位：均衡、高质量或低成本。
- 华北 2（北京）地域可用性。
- 固定版本或滚动版本。
- 非思考模式的输入、输出价格及全部阶梯。
- 价格核对日期。
- “费用为目录价估算，以百炼账单为准”的提示。

首批模型：

- `qwen-plus`，滚动版本。
- `qwen3.7-plus-2026-05-26`，默认推荐。
- `qwen3.7-max-2026-05-20`。
- `qwen3.5-flash-2026-02-23`。
- `deepseek-v4-pro`。
- `deepseek-v4-flash`。
- `deepseek-v3.2`。
- `glm-5.2`。
- `kimi-k2.6`。

模型只有同时满足以下条件才可以进入目录：

- 百炼官方模型目录确认支持。
- 华北 2（北京）地域可用。
- 支持 OpenAI 兼容 Chat Completions。
- 支持非思考模式和 `response_format: { type: "json_object" }` 结构化输出。
- 官方价格页面存在可核对的输入、输出价格。
- 未标记下线。

模型目录是版本化静态数据，不在运行时抓取网页或控制台。目录条目需要记录价格来源、核对日期和阶梯规则。更新目录不会修改已冻结解析器选择的模型 ID。

### 2.3 解析器查看

查看页显示：

- 解析器名称。
- 模型名称和模型 ID。
- 当前目录中可用的计费规则；历史模型无法匹配当前目录时显示“当前目录无价格”。
- 完整提示词，允许复制。
- 创建日期。

不存在编辑入口。

查看页采用紧凑的纵向信息结构：模型名称、定位、地域、版本类型、当前等效版本和核价信息集中在顶部摘要区；计费阶梯在桌面宽度横向排列，窄屏自动换行。完整提示词占满容器宽度并作为页面主体，默认提供足够的阅读高度。复制提示词和复制到新建位于底部右侧操作区。查看页样式必须独立于新建表单，避免通用 `.parser-editor textarea` 规则覆盖只读提示词尺寸。

## 3. 提示词规则

### 3.1 完全可见

新解析器不再根据结构化选项生成隐藏规则。用户提示词文本就是内容分析调用时传给模型的系统指令。

ASR 直播文字、房间 ID 和片段 ID 属于运行时输入数据，不是解析器规则，继续作为独立用户消息发送，无需出现在提示词编辑器中。

系统不得在解析器提示词之外追加用户不可见的业务判断规则。供应商调用所需的非思考模式、JSON 响应格式等协议参数不属于提示词，可以由调用层设置。

### 3.2 默认提示词

新建解析器的默认提示词由当前市场解析器的完整实际提示词还原而来，包含：

- 任务角色和禁止补充外部事实的边界。
- 观点性质定义。
- 当前全部关注范围。
- 原“忽略内容”对应的全部文字规则。
- 逐字证据要求。
- 名称处理规则：“保留主播原始称呼；仅在含义明确时补充标准名称，无法确认时不得猜测。”
- 固定 JSON 输出字段及枚举。

用户可以直接修改、删除或扩展任何一条规则。保存后完整冻结。

## 4. 数据兼容

### 4.1 新解析器格式

新格式保存：

```text
name
model
prompt
```

存储格式增加明确版本，避免将来依赖字段缺失推断：

```text
schemaVersion: 2
```

### 4.2 旧解析器

旧格式继续可读、可运行，不立即批量重写数据库：

```text
description
objectives
filters
normalization
model
advancedPrompt
```

建立唯一的 `materializeParserPrompt` 兼容函数，将旧字段确定性还原为旧解析器实际使用的完整提示词。它同时用于：

- 直播内容分析。
- 旧解析器查看。
- 旧解析器复制新建。

复制旧解析器时生成新格式解析器，并保存已经还原的完整提示词。旧解析器本身保持不可变。

历史观点继续引用原解析器 ID，不受格式升级影响。

## 5. 模型调用与费用估算

内容分析调用继续统一经过 AI 用量网关。调用元数据记录解析器所选的请求模型，响应中记录供应商返回的实际模型和 Token 用量。

价格计算从当前单模型分支改为统一模型价格目录：

1. 根据请求模型和非思考模式查找目录。
2. 根据单次请求输入 Token 数选择价格阶梯。
3. 分别计算输入与输出目录价。
4. 保存价格规则版本和核对日期。
5. 无法匹配时标记 `price_missing`，禁止猜价。

`qwen-plus` 是滚动别名。界面展示官方当前等效版本和当前价格，但调用记录必须保留供应商实际返回模型。后续价格更新只影响新调用的估算，不回写历史调用成本。

## 6. 删除样本测试

删除完整的解析器样本测试垂直链路：

- 渲染端的直播间选择、运行按钮、结果、加载和错误状态。
- preload 的解析器测试 API。
- 主进程 `parsers:test-immutable` IPC handler。
- 临时解析器版本、历史 ASR 取样和 `parser_test` 用量运行。
- 只服务于该入口的测试代码。

不得删除或改动：

- 正式直播内容分析的 `InsightEngine`。
- AI 用量网关。
- 组级解析器解析。
- 历史 ASR 和历史观点读取。
- LLM 连接测试；它属于服务配置，不是解析器样本测试。

删除后通过静态搜索确认不存在渲染端或 IPC 对样本测试的残余引用。

## 7. 错误处理

- 模型目录以外的模型不能用于新建解析器。
- 旧解析器使用历史模型时允许继续运行；目录无价时费用状态为 `price_missing`。
- 提示词为空时禁止保存。
- 模型返回非 JSON 或缺少 Token 用量时继续沿用现有严格失败策略。
- 模型接口拒绝非思考或结构化输出参数时，调用失败并记录真实错误，不自动改用其他模型。

## 8. 验收标准

- 新建和复制新建表单只显示名称、模型、用户提示词。
- 下拉列表只包含已验证目录模型，默认选择 `qwen3.7-plus-2026-05-26`。
- 选中任一模型都能看到完整计费阶梯和核对日期。
- `qwen-plus` 明确标记为滚动版本。
- 默认提示词包含旧系统实际使用的全部业务规则。
- 模型实际收到的解析器系统指令与界面保存的提示词完全一致。
- 旧解析器无需迁移即可继续分析直播内容。
- 查看旧解析器能看到确定性还原后的完整提示词。
- 复制旧解析器生成新格式且提示词内容不丢失。
- 样本测试 UI、preload API、IPC 和 `parser_test` 调用链全部删除。
- 直播监看、ASR、组级绑定、正式内容分析和 AI 用量统计回归测试通过。
- 类型检查、全量测试和 Electron 构建通过。
