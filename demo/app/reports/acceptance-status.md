# 多多直播 macOS v0.5.1 验收状态

更新时间：2026-07-13

交付版本：`0.5.1`

## 本轮范围

- macOS ARM64 客户端；Windows 不作为本轮通过条件。
- 直播监看、逐房间实时 ASR、本地持久化继续保留。
- 新增 LLM 服务配置、版本化解析器、逐房间绑定、主版本与草稿同样本对照、证据优先的观点中心。
- 股票交易决策、自动交易和投资建议不在产品范围；观点中心展示主播原话提炼，并明确提示不构成投资建议。

## 功能验收

- 解析器、不可变已发布版本、单一草稿、房间绑定、正式观点和测试运行均保存到 SQLite。
- 百炼/OpenAI-compatible LLM 密钥经 `safeStorage` 保存，不进入 renderer、SQLite、日志、报告或截图。
- 每个房间可绑定一个已发布解析器或选择“仅保留 ASR”。
- 草稿与已发布版本使用同一批 ASR 对照；草稿结果不进入正式观点流。
- 正式观点保留房间、解析器版本记录、自然时间、来源 ASR ID 和逐字证据。
- 不支持的证据被丢弃；单个无效候选不再丢弃同批其他有效候选。
- 兼容模型把 `evidence`/`conditions` 返回字符串、数组、空字符串、缺省或 `null` 的常见形态。
- 每路独立缓冲和串行分析；单路错误不会中断其他直播间。
- 观点中心按自然时间纵向阅读，可按房间筛选，不混合展示多路原始 ASR。
- 菜单底部显示 `v0.5.1`。
- 直播监看卡片可直接选择已发布解析器或“不使用解析器，仅保留 ASR”。绑定、切换和解绑不调用监看启停接口，不影响 ASR 会话。
- 每张监看卡片提供“实时 ASR / 解析观点”页签，观点严格按房间查询，保留自然时间、证据、条件、关注等级和解析器版本。
- 新观点进入顶部横向提醒队列，点击后定位对应房间卡片、打开观点页签并高亮目标观点；支持单条关闭，队列上限 20。
- 全局提醒设置支持永不、10 秒、30 秒和 60 秒自动关闭，默认 30 秒并持久化；该设置独立保存，不写入 ASR 配置。
- 应用启动历史观点不产生提醒，同一观点 ID 不重复提醒，提醒定时器在关闭和卸载时清理。
- 观点分析在 ASR 静默 8 秒时触发；连续讲话也会在首条缓冲 ASR 后最多 60 秒强制触发，不再无限重置等待。
- 仅配置百炼 ASR 时，首次启动自动创建独立 `qwen-plus` LLM 配置并复用同一个安全密钥引用，不复制或暴露明文 Key。
- 新一次监看只展示本次会话 ASR，不再把数据库历史记录伪装成实时内容。
- 停止后重新监看会清空该房间上一会话的内存热数据；历史数据仍保留，需显式点击“查看历史记录”或向上滚动加载。

- Vitest：25 个测试文件中 24 通过、1 跳过；80 项中 79 通过、1 跳过。
- 20 条固定金标契约样本：precision、recall、nature accuracy、evidence consistency、schema validity 均为 1.0。该数字只证明确定性协议 fixture，不代表真实模型质量。
- 解析器 Electron E2E 连续三次通过：配置、绑定、正式观点、草稿对照、发布、解绑和重启持久化。
- `v0.5.0` Electron E2E 验证新观点提醒可见，点击后正确定位房间卡片、激活观点页签并高亮目标观点；协调器资源计数为 0。
- 440/660/880 Hz 三路音频隔离精确匹配；三路音轨均关闭。
- 单 renderer 崩溃不影响健康路。
- 打包应用三路视频、PCM、ASR WebSocket、IPC 和独立卡片 E2E 通过。

- 密钥扫描零命中。

## 真实直播验证

- Safari 仅用于直播首页发现并记录规范房间 URL，随后回到空白页；未在 Safari 打开房间、录制、监看或读取 Cookie。
- 实际采集使用 Electron 隔离 Session，持续约 5 分钟，未超过 20 分钟限制。
- 5 个候选房间中 4 路产生独立最终 ASR：46、48、36、35 条；1 路无语音结果。
- 使用同一批保存的真实 ASR 做干净单次 LLM 回放。最终报告中三路生成 12 条证据可回指观点；第四路遇到 30 秒模型请求超时并单路进入 `error`；第五路无 ASR。其他房间保持 `idle`，协调器资源计数为 0。
- 模型会保留 ASR 数值矛盾或识别错误并在 rationale 中提示，不能把提炼结果当作校正后的市场事实。

## 验收结论

`v0.5.1` 已将解析器选择、逐房间观点阅读和新观点提醒接入直播监看主工作台，修复连续语音长期不触发及百炼 LLM 未配置却无明显反馈的问题，同时保持解析器为 ASR 后置旁路。
