### 浏览器账号边界

- Safari 已由用户登录抖音账号，仅允许用于搜索、查找博主和获取直播间链接。
- 不使用 Safari 多开直播，不使用 Safari 做并发播放、音频采集或 ASR 样本录制，避免影响用户账号风控。
- 从 Safari 获取到直播间后，只保留规范化链接：

```text
https://live.douyin.com/{room_id}
```

- 示例：`https://live.douyin.com/727845008784`。
- 链接中 `?` 后面的查询参数、来源参数、分享参数均不进入样本清单。
- 播放验证、并发验证、音频捕获和 ASR 测试必须使用无登录状态的独立 Chrome profile / user-data-dir。

- 当前测试环境以用户正在使用的这台电脑为准。

- 使用阿里云百炼相关能力。

## 仍需在执行中确认

- macOS 具体版本、CPU、内存已记录；仍需确认浏览器版本。
- 是否允许安装或启用虚拟音频相关工具。
- 百炼具体使用的模型、接口类型、计费方式和并发限制。
- 直播 URL 在实际测试时是否仍然处于开播、公开、匿名可观看状态；若已下播，可从抖音直播首页实时更换在线直播间。

## 对计划的影响

- 阶段 1 可以优先按 macOS 方案验证独立浏览器 Profile / 独立进程。
- 音频捕获方案应优先评估 macOS 上的页面级音频捕获；如不可行，再评估进程级或虚拟音频通道。
- 阶段 2 可以直接按“云端 ASR 可用”的前提设计百炼接入配置，但必须保留 Key 不入库。
- 测试期可以保存音频和 ASR 文本，因此阶段 0 的标注集和阶段 5 的回放能力可以落地。
