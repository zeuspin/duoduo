# Task 1.1 候选获取阻塞说明

## 当前结论

Task 1.1 继续执行三路股票 / 财经 20 分钟自愈监控前，需要先获得 4 到 5 个当前可捕获的股票 / 财经直播候选。

当前自动候选获取路径已经尝试：

- 无登录 Chrome 直播首页首屏发现。
- 无登录 Chrome 直播首页滚动发现。
- 无登录 Chrome 搜索 `股票直播` / `财经直播`。
- 公开网页搜索 `live.douyin.com` 股票 / 财经房间。
- Safari 登录态首页只读 URL / 可访问性树读取。

结果仍不足：最新 run66 / run68 均未补足候选，run66 只有 2 路可捕获，run68 为 0 路可捕获。

## 为什么暂停

继续跑三路监控需要至少 3 个当前可捕获股票 / 财经候选；验证自愈还需要 1 到 2 个 standby。因此实际启动条件是：

- 最低：3 个当前可捕获股票 / 财经直播。
- 推荐：4 到 5 个当前可捕获股票 / 财经直播。

当前候选不足时继续运行，会把“主播下播 / 无可用直播源”误判成容器并发或自愈链路失败。

## 需要用户提供什么

请从 Safari 登录态抖音直播首页人工筛选股票 / 财经 / 看盘直播，提供 4 到 8 个规范化链接，格式如下：

```text
https://live.douyin.com/123456789
https://live.douyin.com/234567890
https://live.douyin.com/345678901
https://live.douyin.com/456789012
```

只需要保留数字房间 ID，去掉 `?` 后面的所有参数。

## 后续动作

拿到新链接后，执行顺序为：

1. 写入 `demo/reports/user-specified-live-candidates-*.json`。
2. 使用无登录 Chrome profile 做候选门禁。
3. 若至少 4 到 5 个可捕获，执行不超过 20 分钟的三路自愈监控。
4. 对照验收标准更新 Task 1.1 状态。
