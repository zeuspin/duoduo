## 复查方法

用以下方式读取窗口标题，不需要登录、不需要点击页面：

```bash
ps aux | rg 'Google Chrome --user-data-dir=/Users/xuke/Documents/getian/duoduo/demo/runtime/chrome-profiles/(run7|run6|run5|run4|run2|live|profile)-'
```

通过条件：

- 三个窗口标题仍包含对应直播间名称。
- 三个窗口标题仍包含“正在播放音频”。
- 未出现登录拦截。
- 需要先启动一轮三路均显示“正在播放音频”的新 run，才能重新设定 2 小时目标时间。

未通过或需补测：

- 任一窗口消失、直播下播、标题不再显示“正在播放音频”。
- 任一窗口要求登录。
- 任一路停止导致其他路停止。
- 未满 2 小时即结束观察。
