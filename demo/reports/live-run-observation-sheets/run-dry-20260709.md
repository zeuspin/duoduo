- 只使用未登录的独立 Chrome user-data-dir 播放直播。

- 三路页面均为目标直播间，且观察到正在播放音频，才可开始 2 小时计时。

## 验收标准

- 至少一种方案满足 3 路直播连续播放 2 小时。
- 任一路刷新、关闭、异常退出不导致其他直播停止。
- 不要求、不输入、不保存任何抖音账号信息。
- 重复 3 个交易日后，核心方案仍能稳定并行。
