# 多路直播音频与 ASR 验证口径

更新时间：2026-07-11

## 当前阶段目标

本阶段先放弃股票 / 财经内容要求，只验证多路直播音频链路：

- 多路直播可以同时打开和监控。
- 每路直播音频可以独立录制。
- 各路录音互不串音。
- 每路录音可以调用百炼 / DashScope ASR。
- ASR 可以返回文本。

## 非目标

- 不验证股票 / 财经直播内容。
- 不验证看盘语义。
- 不做 2 小时长测。
- 不做 3 个交易日复测。
- 不做完整产品 UI。
- 不要求人工标注。

## 本阶段通过标准

| 项目 | 标准 |
| --- | --- |
| 候选门禁 | 至少 3 路公开视频直播可由无登录 Chrome 播放并存在音轨 |
| 同时录音 | 至少 3 路同时录制，每路生成有效音频文件 |
| 音频隔离 | 使用页面级 `video.captureStream()` 捕获，每路从各自 Chrome profile/CDP 页面采集；录制文件与 route/room_id 一一对应 |
| ASR | 每路至少 1 段有效录音完成转码并调用百炼 / DashScope ASR，返回文本或句子事件 |
| 清理 | 结束后测试 Chrome、捕获进程和测试 profile 均为 0 |
| 安全 | 不写入 `.env`、key、cookie、登录态或 Safari 账号信息 |

## 执行边界

- 单次测试最长不超过 20 分钟。
- Safari 只允许用于找链接；本阶段优先使用无登录 Chrome 自动发现候选。
- 播放、录音、ASR 测试全部使用无登录 Chrome profile。
