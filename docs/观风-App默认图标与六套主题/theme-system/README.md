# 观风 App 主题系统

## 默认 App Icon

正式打包使用 `01-ink`（墨黑 × 宣纸白）。其他五款不替换系统桌面图标，作为软件内“外观与主题”页面的视觉入口。

## 六套主题

| ID | 中文名 | 模式 | 主色 | 页面背景 |
|---|---|---|---|---|
| `ink` | 宣纸墨 | 浅色 | `#111111` | `#F3EFE5` |
| `navy` | 观海蓝 | 浅色 | `#163A4A` | `#F2F5F3` |
| `jade` | 松石青 | 浅色 | `#174C43` | `#DCE9E1` |
| `cinnabar` | 朱砂红 | 浅色 | `#A52D27` | `#F3E8D5` |
| `gold` | 玄黑金 | 深色 | `#D2AA5A` | `#171717` |
| `violet` | 云雾紫 | 浅色 | `#4A315E` | `#EEEAF2` |

## 开发接入

- `themes.json`：跨平台设计令牌，可映射到 iOS、Android、Flutter、React Native。
- `themes.css`：Web/CSS 变量，根节点设置 `data-theme="ink"` 等 ID 即可切换。
- `主题切换演示.html`：可交互查看六套主题效果。
- `观风-六套主题视觉规范.svg/png`：设计与产品评审参考。

建议首次启动跟随系统外观，但主题默认值使用 `ink`。用户主动选择后，将主题 ID 持久化到本地设置。
